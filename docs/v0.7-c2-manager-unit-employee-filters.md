# v0.7-C2 Implementation & Acceptance Report: Manager Authorized Unit & Employee Filters

## Overview
Version `v0.7-C2` adds safe, secure filtering by **Organization Unit** and **Employee** to the Manager Dashboard (`Tổng quan đơn vị`). All filter options are strictly scoped and sourced from the backend based on the authenticated Manager's permitted reporting hierarchy (`resolveManagerScopeUnits`).

---

## Key Features & Architectural Guarantees

1. **Secure Backend-Driven Reporting Options Endpoint**:
   - Created `GET /api/dashboard/reporting-options`.
   - Strictly validates that the user holds `manager`, `executive`, or `admin` role and is active.
   - Leverages `resolveManagerScopeUnits` to dynamically compute permitted organization unit IDs and descendant sub-units.
   - Queries `organization_members` joined with active `profiles` restricted strictly to the manager's permitted unit scope.
   - Prevents unauthorized privilege escalation and ensures system-wide data is never exposed.

2. **Frontend Filter Controls & State Synchronization**:
   - Added dropdown selectors for **Organization Unit** and **Employee** directly in the Manager Dashboard header toolbar.
   - **Filter Hierarchy & Relationship**: Selecting an organization unit automatically filters the employee dropdown list to show only personnel belonging to that unit (or showing all permitted employees if no unit is selected).
   - **Reset & Fallback**: If a selected unit or employee becomes invalid or unauthorized, the frontend and backend gracefully reset state and handle 403 responses safely.

3. **Strict Scope Compliance**:
   - No database schema changes, no new tables, no RLS modifications.
   - No summary cards, tables, or charts added in this phase.
   - Read-only dashboard safety maintained.
