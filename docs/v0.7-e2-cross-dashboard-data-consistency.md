# Dashboard Data Consistency (v0.7-E2)

## Overview
This document tracks the verification and enforcement of data consistency across Staff, Manager, and Executive dashboards in the Work + KPI project.

## Data-Source Matrix
| Nhóm số liệu | Staff service/API | Manager service/API | Executive service/API | Định nghĩa chuẩn |
| :--- | :--- | :--- | :--- | :--- |
| Task | `taskService.ts` | `dashboardAggregationService.ts` | `dashboardComparisonService.ts` | Shared `taskService` definitions |
| Daily Report | `daily-report.service.ts` | `manager-report.service.ts` | (Summary aggregation) | Shared reporting contract |
| Attention | `notification.service.ts` | `notification.service.ts` | (N/A) | Notification schema |
| Metric | `metric.service.ts` | `dashboardMetricAggregationService.ts` | `dashboardTrendService.ts` | Metric definitions |
| KPI | `kpi.service.ts` | `kpiDashboardService.ts` | `kpiDashboardService.ts` | KPI Engine |

## Consistency Matrix
| Nhóm số liệu | Scope (Manager vs Exec selected) | Method | Deduplication rule |
| :--- | :--- | :--- | :--- |
| Task | Equal | Sum | Task ID unique |
| Daily Report | Equal | Employee-day | (User ID, Date) unique |
| Metric | Equal | Definition-specific | Definition ID unique |
| KPI | Equal | Engine-specific | Definition ID unique |
1. **Scope-based Aggregation**: Manager and Executive dashboards aggregate data based on scope (primary unit + descendants), while Staff is personal-only.
2. **Deduplication**: Task deduplication must use unique Task ID across all dashboards.
3. **Daily Report**: Employee-day aggregation must count unique (employee_id, date) pairs regardless of submission source.
4. **Dates**: All dashboards must use inclusive `date_from` and `date_to` logic based on UTC or defined system timezone.
5. **Missing Values**: Do not convert missing aggregation values (e.g., null) to zero in frontend adapters unless explicitly required by the KPI/Metric Engine.
