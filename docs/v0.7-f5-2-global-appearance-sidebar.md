# v0.7-F5.2 – Global Appearance Settings & Smooth Sidebar Documentation

## Overview
Milestone `v0.7-F5.2` introduces global appearance settings and a refined, smooth sidebar experience across the School Task & KPI Management platform.

---

## Key Features & Enhancements

### 1. Global Appearance Settings (`AppearanceContext`)
- **Modes**: Supports `light` (Sáng), `dark` (Tối), and `system` (Theo thiết bị).
- **Accents**: Supports `indigo` (Tím chủ đạo), `blue` (Xanh dương), and `teal` (Xanh ngọc).
- **Persistence**: Automatically syncs with backend system settings (`system_settings` table via `/api/admin/settings` and `/api/settings/public`) and `localStorage` as a fast client-side fallback.
- **CSS Variable Integration**: Dynamically updates `document.documentElement` with `data-theme-mode` (`light`/`dark`) and `data-theme-accent` (`indigo`/`blue`/`teal`), controlling CSS custom properties (`--color-primary`, `--color-page-bg`, `--color-surface`, etc.) in `index.css`.

### 2. Admin System Settings Integration
- Added an **"Giao diện hệ thống"** section in **Admin → Cấu hình hệ thống** (`SystemSettingsView`).
- Allows administrators to configure default system appearance modes and accent colors with instant preview options and a **"Khôi phục mặc định"** reset button.

### 3. Redesigned Smooth Sidebar
- **Toggle Button**: Relocated the collapse/expand toggle button to the top-right edge of the sidebar header for natural ergonomics.
- **Smooth Transitions**: Applied precise CSS width and transform transitions (avoiding blunt `transition-all`) respecting `prefers-reduced-motion`.
- **Collapsed Tooltips**: In collapsed desktop mode (~80px), hovering over navigation items and the logout button displays floating tooltips with clear labels and role badges.
- **Mobile Drawer**: Fully responsive mobile drawer with backdrop blur, smooth sliding entrance, and automatic closing upon menu selection.
