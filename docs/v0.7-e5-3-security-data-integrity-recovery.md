## 3. Trust-Boundary Map (Bản đồ Ranh giới Tin cậy)

| Thành phần | Dữ liệu đầu vào | Nguồn tin cậy | Kiểm tra quyền | Dữ liệu trả về |
|------------|-----------------|---------------|----------------|----------------|
| **Frontend UI** | Input người dùng, URL query, click events | Không tin cậy | Giao diện điều hướng, Safe tab resolution | State hiển thị, form payloads |
| **Auth Session** | JWT Access Token, refresh tokens | Supabase Auth (Đáng tin cậy) | Token signature, expiry, revocation | Authenticated user identity |
| **Backend API** | HTTP Request headers, query, body | Headers/Token (Xác thực) | RBAC Token Resolver, Role Guards | HTTP Response, Sanitized Errors |
| **Reporting Scope Service** | Authenticated User + Filter Request | Backend Service logic | Role scope mapping, Unit hierarchy | Resolved Reporting Scope |
| **Dashboard Services** | Scope + Filter Request | Database / Aggregation Adapters | Scope boundary checks | Unified Dashboard Aggregate Data |
| **Supabase / Database** | SQL / RPC / RLS Queries | Database Engine | RLS Policies, Foreign keys | Filtered Rows & Aggregates |

*Lưu ý cốt lõi: Frontend không được xem là nguồn quyền đáng tin cậy. Backend giải quyết toàn bộ phạm vi báo cáo dựa trên danh tính đã xác thực.*
