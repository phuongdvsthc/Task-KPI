# v0.7-C5.2 – Manager Metric & KPI Charts

## Overview
v0.7-C5.2 implements two Manager performance visualizations:
1. **Metric Trend Chart**: Line chart displaying time-series values for one compatible Metric at a time, with a selector in the section **Xu hướng chỉ số công việc** (Section 3).
2. **KPI Period Chart**: Bar chart displaying KPI results (achievement rate / weighted score) across discrete evaluation periods in the section **Kết quả KPI theo kỳ** (Section 4).

## Key Design Principles & Architecture
- **Single Source of Truth**: Powered directly by the unified Dashboard aggregate response (`UnifiedDashboardResponse`) matching the currently selected authorized scope. Zero paginated C4 table rows or organization-wide client calculations are used.
- **No Ranking or Comparison**: Strictly avoids employee ranking, top/bottom employee lists, or unit comparisons. Reflects aggregate scope only.
- **Live vs. Official Distinction**: Clearly labels KPI periods as `Chính thức` (Official) or `Tạm tính` (Live) based on backend snapshot state.
- **Filter Integration**: Fully respects current date range, unit selection, and employee filters.
- **Accessibility & Responsive Design**: Semantic headings, accessible descriptions, responsive Recharts containers, and neutral empty states when data is absent.
