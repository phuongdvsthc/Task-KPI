# Dashboard Routing & Role Access Integration (v0.7-E1)

## Overview
This document maps the routing and role-based access control (RBAC) mechanism for the Work + KPI project. The application utilizes a hash-based routing system controlled within `AppLayout.tsx`.

## Route Map (Current Implementation)
| Route Hash | Component | Authorized Roles |
| :--- | :--- | :--- |
| `#/overview` | `DashboardView` | All (Authenticated) |
| `#/staff-dashboard` | `StaffDashboardView` | Staff, Manager, Admin |
| `#/manager-dashboard` | `ManagerDashboardView` | Manager, Admin |
| `#/executive-dashboard` | `ExecutiveDashboardView` | Executive, Admin |
| `#/tasks` | `TaskList` | All (Authenticated) |
| `#/metrics` | `MetricEntryView` | All (Authenticated) |
| `#/kpis` | `StaffMyKpiView`/`KpiFoundationLayout`| All (Authenticated) |
| `#/daily-reports` | `DailyReportManager` | All (Authenticated) |
| `#/reports` | `PlaceholderView` | All (Authenticated) |
| `#/admin` | `AdminLayout` | Admin |
| `#/account/security` | `SecurityView` | All (Authenticated) |

## Role Source
- Role is determined by `systemRole` provided by `AuthContext`.
- `AuthContext` fetches this directly from `public.profiles.system_role` via Supabase at login.

## Role Access Matrix (Target)
| Role | Staff Dashboard | Manager Dashboard | Executive Dashboard | Admin |
| :--- | :--- | :--- | :--- | :--- |
| **Staff** | Allowed | Forbidden | Forbidden | Forbidden |
| **Manager**| Allowed (if logic permits) | Allowed | Forbidden | Forbidden |
| **Executive**| Allowed (if logic permits) | Allowed (if logic permits) | Allowed | Forbidden |
| **Admin** | Allowed (if logic permits) | Allowed (if logic permits) | Forbidden | Allowed |

## Navigation Behavior
- **Sidebar**: Filters `MENU_ITEMS` based on `systemRole`.
- **Route Guard**: `AppLayout.tsx` handles conditional rendering and `safeTab` logic to prevent unauthorized tab selection.

## Known Gaps
- Currently, navigation is restricted based on `systemRole` flags in `Sidebar.tsx` and conditional rendering in `AppLayout.tsx`, but direct URL access might need stricter enforcement in `AppLayout`.
