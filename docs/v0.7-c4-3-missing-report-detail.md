# v0.7-C4.3 – Manager Missing Daily Report Detail

## Overview
v0.7-C4.3 implements the manager missing daily report detail feature, allowing a manager to click on an employee's missing-report count within the Team Monitoring Table and view the exact missing dates within the current reporting period.

## Key Features & Architecture
1. **Secure API Endpoint (`GET /api/dashboard/team-monitoring/missing-reports`)**:
   - Requires authentication (`authenticateUser`) and manager/executive/admin role authorization.
   - Enforces reporting scope checks via `reportingScopeService.resolveReportingScope`.
   - Validates `employee_id` and ensures it belongs to the manager's permitted scope (returning 403 if out of scope).
   - Computes expected business weekdays and identifies missing report dates consistent with C4.1/C4.2 aggregation rules.
   - Read-only: no database writes or updates.

2. **Interactive UI (`MissingReportsModal`)**:
   - Triggered when clicking the missing report badge for an employee in the Manager Employee Monitoring Table.
   - Displays summary card (expected days, submitted days, missing days) and a chronological list of missing dates in Vietnamese date format.
   - Fully accessible with keyboard navigation (Escape key support) and focus management.

3. **Client API Client (`dashboardApiClient.getMissingReportsDetail`)**:
   - Strongly typed TypeScript client method calling the missing-reports endpoint.
