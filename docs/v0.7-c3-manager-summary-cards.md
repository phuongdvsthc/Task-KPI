# v0.7-C3 Implementation & Acceptance Report: Manager Dashboard Summary Cards

## Overview
Version `v0.7-C3` introduces summary cards for the Manager Dashboard (`Tổng quan đơn vị`), displaying tasks, daily report completion, metric data, KPI results, and attention items for the currently selected permitted scope.

---

## Key Features & Architectural Guarantees

1. **Filtered-Scope Description Label**:
   - Displays a dynamic badge above the summary cards indicating the current scope context:
     - “Tất cả đơn vị được phân quyền” (when no specific unit or employee is selected).
     - “Đơn vị: [Unit Name]” (when an authorized organization unit is selected).
     - “Nhân viên: [Employee Name]” (when a specific employee within the scope is selected).
   - Ensures managers have immediate clarity on their active reporting boundary without exposing internal IDs or system-wide scope.

2. **Task Summary Cards ("Tổng quan công việc")**:
   - Displays backend-driven values: Total tasks (`Tổng công việc`), Completed (`Đã hoàn thành`), In-progress (`Đang thực hiện`), Overdue (`Quá hạn`), and Completion Rate (`Tỷ lệ hoàn thành`).
   - Cards are noninteractive in C3.

3. **Daily-Report Summary Cards ("Tình hình báo cáo hằng ngày")**:
   - Utilizes employee-day terminology: Expected employee-days (`Lượt ngày cần báo cáo`), Submitted employee-days (`Lượt ngày đã báo cáo`), Missing employee-days (`Lượt ngày còn thiếu`), and Completion Rate (`Tỷ lệ hoàn thành báo cáo`).
   - Multiple report sources for one employee/date count once; different employees on the same date count as separate employee reporting days.

4. **Metric Summary Cards ("Dữ liệu chỉ số công việc")**:
   - Displays metric definition count (`Số chỉ số có dữ liệu`), entry count / record count (`Lượt ghi nhận`), employee count (`Nhân viên có dữ liệu`), and source count (`Nguồn có dữ liệu`).

5. **KPI Summary Cards ("KPI trong phạm vi theo dõi")**:
   - Displays assigned KPI count (`KPI được giao`), active (`KPI đang thực hiện`), achieved (`KPI đạt`), pending review (`Chờ đánh giá`), completion rate (`Tỷ lệ hoàn thành`), and weighted score (`Điểm tổng hợp`).

6. **Attention Summary ("Cần chú ý")**:
   - Displays unread notifications (`Thông báo chưa đọc`), required announcements pending acknowledgement (`Thông báo cần xác nhận`), announcements not viewed (`Thông báo chưa xem`), and total attention count (`Tổng cần chú ý`).
   - Strictly respects the Manager's personal notification scope without team-wide notification misattribution or write actions.

7. **Zero, Null & Partial Data Handling**:
   - Valid zeros display as `0`.
   - Null or missing values display as “Chưa có dữ liệu”.
   - Partial responses maintain available card groups while preserving warnings.
