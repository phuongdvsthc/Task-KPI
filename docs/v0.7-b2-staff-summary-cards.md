# v0.7-B2: Staff Dashboard Summary Cards

**Project:** School Task & KPI Management (STHC Work + KPI)  
**Milestone:** v0.7 – Staff Dashboard  
**Version:** v0.7-B2  
**Status:** Staff Dashboard Summary Cards  

---

## 1. Overview

This document specifies the implementation of personal summary cards for the authenticated Staff user (`v0.7-B2`), displaying structured operational metrics, daily report completion, KPI status, and attention items using the real A5 Dashboard API response (`GET /api/dashboard/reporting`).

---

## 2. Card Groups & API Field Mappings

### Group 1: Công việc của tôi (Tasks)
- **Tổng công việc:** `summary.operations.tasks.total_tasks` / `total`
- **Đã hoàn thành:** `summary.operations.tasks.completed_tasks`
- **Đang thực hiện:** `summary.operations.tasks.in_progress_tasks`
- **Quá hạn:** `summary.operations.tasks.overdue_tasks` (highlighted in danger/warning state if > 0)
- **Tỷ lệ hoàn thành:** `summary.operations.tasks.completion_rate` (formatted as percentage)

### Group 2: Báo cáo hằng ngày (Daily Reports)
- **Ngày cần báo cáo:** `summary.operations.daily_reports.expected_reporting_days`
- **Ngày đã báo cáo:** `summary.operations.daily_reports.submitted_reports`
- **Ngày còn thiếu:** `summary.operations.daily_reports.missing_reports` (highlighted if > 0)
- **Tỷ lệ hoàn thành báo cáo:** `summary.operations.daily_reports.reporting_completion_rate` (formatted as percentage)

### Group 3: KPI cá nhân (KPIs)
- **KPI được giao:** `summary.kpis.assignment_count`
- **KPI đang thực hiện:** `summary.kpis.active_kpi_count`
- **KPI đạt:** `summary.kpis.achieved_kpi_count`
- **Chờ đánh giá:** `summary.kpis.pending_review_count`
- **Tỷ lệ hoàn thành:** `summary.kpis.overall_achievement_rate` (formatted as percentage)
- **Điểm tổng hợp:** `summary.kpis.weighted_score`

### Group 4: Cần chú ý (Attention)
- **Thông báo chưa đọc:** `summary.operations.attention.unread_notifications`
- **Cần xác nhận thông báo:** `summary.operations.attention.required_announcements_pending_acknowledgement`
- **Thông báo chưa xem:** `summary.operations.attention.announcements_not_viewed`
- **Tổng cần chú ý:** `summary.operations.attention.pending_attention_total`

---

## 3. Formatting & Zero vs. Unavailable Behavior
- Counts are formatted using locale-aware integers.
- Percentages are formatted with fixed decimal precision without double `%`.
- Missing or null data points are clearly rendered as `"Chưa có dữ liệu"`, distinguishing them safely from true `0` values.
- Cards are non-interactive in B2 (no drill-down navigation).

---

## 4. Omitted & Deferred Items
- **Omitted:** Due-soon task cards, at-risk KPI cards, KPI overdue cards, low-completion warnings, and charts/detailed lists.
- **Deferred:** v0.7-B3 (Daily Report Management & Submission), v0.7-B4 (Metric Entry Tables), and v0.7-B5 (KPI Review Details).
