# v0.7-D2 Executive/BGH Unit & Comparison Filters

## Endpoint
- Reused: `GET /api/dashboard/reporting-options`

## Authorization
- Role-based authorization is enforced in `dashboardOptionsService.ts`. Executives are permitted to access organization units but not employees.

## UI Components
- Reporting Scope Filter: Single-select dropdown (`Phạm vi báo cáo`).
- Comparison Unit Filter: Multi-select button list (`Đơn vị cần so sánh`).

## Logic
- Ancestor/descendant overlap is validated to prevent double counting.
- Comparison scope is restricted to the chosen reporting scope unit's subtree.
- Reporting scope defaults to "Toàn trường".

## Responsive & Accessibility
- Selectors and multi-select components are designed to be responsive and keyboard-accessible.
