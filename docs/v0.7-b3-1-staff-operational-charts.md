# v0.7-B3.1: Staff Operational Charts

**Project:** School Task & KPI Management (STHC Work + KPI)  
**Milestone:** v0.7 – Staff Dashboard  
**Version:** v0.7-B3.1  
**Status:** Staff Operational Charts  

---

## 1. Overview

This document specifies the implementation of personal operational charts for the authenticated Staff user (`v0.7-B3.1`), adding two clear visualizations:
1. **Phân bổ công việc (Task Status Bar Chart):** Compares mutually exclusive task status counts (Completed, In Progress, Not Started) using Recharts.
2. **Tiến độ báo cáo hằng ngày (Daily Report Trend Line Chart):** Displays chronological daily report submissions over the selected reporting period.

---

## 2. Chart Library & Components
- **Library:** Recharts (`ResponsiveContainer`, `BarChart`, `Bar`, `XAxis`, `YAxis`, `Tooltip`, `CartesianGrid`, `LineChart`, `Line`, etc.).
- **Components Created/Reused:**
  - Integrated directly inside `src/components/dashboard/StaffDashboardView.tsx`.
  - Reused existing responsive containers and Tailwind styling conventions.

---

## 3. Task Category Overlap Inspection
- **Inspection Result:** `overdue_tasks` can overlap with `in_progress_tasks`, and `tasks_without_due_date` can overlap with any status.
- **Composition Decision:** To avoid false part-to-whole compositions (such as in pie charts where overlapping categories distort totals), we use mutually exclusive status categories (`Đã hoàn thành`, `Đang thực hiện`, `Chưa bắt đầu`) for the Bar Chart. `Quá hạn` continues to be prominently displayed as a summary metric card.

---

## 4. API Field Mappings
- **Task Status Chart:**
  - Completed: `summary.operations.tasks.completed_tasks`
  - In Progress: `summary.operations.tasks.in_progress_tasks`
  - Not Started: `summary.operations.tasks.not_started_tasks`
- **Daily Report Trend Chart:**
  - Series data: `summary.operations.daily_reports.reports_by_date` or `series.daily_reports` (sorted chronologically by `date`, with `submitted_count`).

---

## 5. Empty & Partial Behavior
- If all values are zero or series is empty, a clean neutral empty state message is rendered without breaking other dashboard sections.
- Supports backend partial response warnings cleanly.

---

## 6. Accessibility & Responsive
- Visible section titles and accessible descriptions.
- Responsive width using Recharts `ResponsiveContainer` and CSS constraints.
- Accessible text representations and non-color-only state communication.
