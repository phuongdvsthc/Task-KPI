# v0.7-C6.1 – Manager Attention Panel & Safe Navigation

## Overview
v0.7-C6.1 implements the factual Manager Attention Panel ("Cần chú ý") in `ManagerDashboardView.tsx` with safe navigation to authorized existing routes:
1. **Overdue Work**: `overdue_tasks` mapped to `#/tasks?status=overdue`.
2. **Missing Daily Reports**: `missing_reports` mapped to `#/daily-reports`.
3. **KPI Pending Review**: `pending_review_count` mapped to `#/kpis`.
4. **KPI Missing Actual**: `missing_actual_count` mapped to `#/kpis`.
5. **Manager Personal Notifications**: `unread_notifications` and `pending_required_acknowledgements` clearly distinguished and mapped to `#/tasks`.

## Architectural Rules & Guarantees
- **Read-Only**: Zero database writes, zero reminder actions, zero notifications sent or marked read, zero task updates.
- **Scope Separation**: Team-level operational and KPI warnings are strictly distinguished from Manager personal notifications.
- **Filter Synchronization**: Attention counts and items dynamically update when date ranges, units, or employees change.
- **Empty & Error States**: Clean neutral empty message ("Hiện không có nội dung nào cần chú ý trong phạm vi đang chọn") and localized error retry handling.
