# v0.8-A1 – Admission Groups, Programs and Campaigns Database Foundation

## 1. Mục tiêu và Phạm vi

Triển khai nền tảng cơ sở dữ liệu (Database Foundation) cho Phân hệ Tuyển sinh (Admission Module), bao gồm:
1. **Nhóm tuyển sinh (`admission_groups`)**: Phân định nhóm tuyển sinh (ví dụ: Trung cấp chính quy, Đào tạo ngắn hạn).
2. **Danh mục ngành/lớp/khóa học (`admission_programs`)**: Quản lý danh mục ngành tuyển sinh trình độ Trung cấp hoặc các khóa học ngắn hạn.
3. **Đợt tuyển sinh (`admission_campaigns`)**: Quản lý các kỳ/đợt tuyển sinh theo năm và nhóm tuyển sinh.

### Ranh giới phạm vi (Scope Boundaries)
- **Database Foundation Only**: Chỉ triển khai tầng database, migration, model types, service contracts và automated self-tests.
- **Không làm trong bước này**:
  - Không xây dựng UI / màn hình giao diện.
  - Không thêm menu hay route mới vào ứng dụng.
  - Không thực hiện import Excel.
  - Không nhập kết quả hay kế hoạch tuyển sinh.
  - Không liên kết / can thiệp vào module KPI hiện hữu.
  - Không thay đổi giao diện sáng / tối / blue.
  - Không sửa đổi bất kỳ bảng hay policy bảo mật hiện hữu nào.

## 2. Thiết kế Cơ sở dữ liệu

### 2.1 Bảng `admission_groups` (Nhóm tuyển sinh)
- `id` UUID PRIMARY KEY DEFAULT `gen_random_uuid()`
- `code` TEXT NOT NULL UNIQUE (ví dụ: `TRUNG_CAP`, `NGAN_HAN`)
- `name` TEXT NOT NULL
- `description` TEXT
- `is_active` BOOLEAN NOT NULL DEFAULT TRUE
- `sort_order` INTEGER NOT NULL DEFAULT 0
- `created_at` TIMESTAMPTZ NOT NULL DEFAULT NOW()
- `updated_at` TIMESTAMPTZ NOT NULL DEFAULT NOW()
- `created_by` UUID REFERENCES `auth.users(id)` ON DELETE SET NULL
- `updated_by` UUID REFERENCES `auth.users(id)` ON DELETE SET NULL
- **Ràng buộc**: `uq_admission_groups_code`, độ dài tối thiểu của `code` và `name` >= 2 ký tự.
- **Index**: `idx_admission_groups_code`, `idx_admission_groups_is_active`, `idx_admission_groups_sort_order`.

### 2.2 Bảng `admission_programs` (Danh mục ngành/lớp/khóa học)
- `id` UUID PRIMARY KEY DEFAULT `gen_random_uuid()`
- `group_id` UUID NOT NULL REFERENCES `admission_groups(id)` ON DELETE RESTRICT
- `code` TEXT NOT NULL UNIQUE
- `name` TEXT NOT NULL
- `description` TEXT
- `training_level` TEXT NOT NULL DEFAULT 'trung_cap' CHECK (`training_level` IN ('trung_cap', 'ngan_han', 'so_cap', 'chung_chi', 'khac'))
- `duration` TEXT
- `is_active` BOOLEAN NOT NULL DEFAULT TRUE
- `sort_order` INTEGER NOT NULL DEFAULT 0
- `created_at` TIMESTAMPTZ NOT NULL DEFAULT NOW()
- `updated_at` TIMESTAMPTZ NOT NULL DEFAULT NOW()
- `created_by` UUID REFERENCES `auth.users(id)` ON DELETE SET NULL
- `updated_by` UUID REFERENCES `auth.users(id)` ON DELETE SET NULL
- **Ràng buộc**: `uq_admission_programs_code`, `ON DELETE RESTRICT` ngăn chặn mồ côi dữ liệu khi nhóm còn chương trình.
- **Index**: `idx_admission_programs_group_id`, `idx_admission_programs_code`, `idx_admission_programs_is_active`, `idx_admission_programs_training_level`, `idx_admission_programs_sort_order`.

### 2.3 Bảng `admission_campaigns` (Đợt tuyển sinh)
- `id` UUID PRIMARY KEY DEFAULT `gen_random_uuid()`
- `group_id` UUID NOT NULL REFERENCES `admission_groups(id)` ON DELETE RESTRICT
- `code` TEXT NOT NULL UNIQUE
- `name` TEXT NOT NULL
- `year` INTEGER NOT NULL CHECK (`year` >= 2000 AND `year` <= 2100)
- `period_number` INTEGER NOT NULL CHECK (`period_number` > 0)
- `start_date` DATE
- `end_date` DATE CHECK (`end_date IS NULL OR start_date IS NULL OR end_date >= start_date`)
- `status` TEXT NOT NULL DEFAULT 'planning' CHECK (`status` IN ('planning', 'active', 'closed', 'completed', 'archived'))
- `is_active` BOOLEAN NOT NULL DEFAULT TRUE
- `description` TEXT
- `created_at` TIMESTAMPTZ NOT NULL DEFAULT NOW()
- `updated_at` TIMESTAMPTZ NOT NULL DEFAULT NOW()
- `created_by` UUID REFERENCES `auth.users(id)` ON DELETE SET NULL
- `updated_by` UUID REFERENCES `auth.users(id)` ON DELETE SET NULL
- **Ràng buộc**: `uq_admission_campaigns_code`, `uq_admission_campaigns_group_year_period` (duy nhất theo bộ `[group_id, year, period_number]`).
- **Index**: `idx_admission_campaigns_group_id`, `idx_admission_campaigns_year`, `idx_admission_campaigns_status`, `idx_admission_campaigns_is_active`, `idx_admission_campaigns_year_period`, `idx_admission_campaigns_dates`.

## 3. Triggers & Row Level Security (RLS)

- **Audit Trigger**: Gắn trigger tự động cập nhật `updated_at` khi UPDATE trên cả 3 bảng thông qua hàm chuẩn `update_updated_at_column()`.
- **Bảo mật RLS**:
  - Đã bật `ENABLE ROW LEVEL SECURITY` trên cả 3 bảng.
  - Tuyệt đối không cho phép truy cập nặc danh (zero public / anon policies).
  - Quyền SELECT: Cho phép tất cả người dùng xác thực (`TO authenticated`) xem các bản ghi đang kích hoạt (`is_active = TRUE`) hoặc người dùng có vai trò quản lý (`admin`, `executive`, `manager`).
  - Quyền INSERT / UPDATE / DELETE: Giới hạn nghiêm ngặt cho vai trò `admin`.

## 4. Dữ liệu mồi (Seed Fixtures)

- **Nhóm tuyển sinh (`admission_groups`)**: 2 nhóm khởi tạo:
  1. `TRUNG_CAP` - Trung cấp (Chương trình đào tạo trình độ Trung cấp chính quy)
  2. `NGAN_HAN` - Đào tạo ngắn hạn (Các khóa đào tạo, bồi dưỡng kỹ năng nghề và chứng chỉ ngắn hạn)
- **Đợt tuyển sinh năm 2026 (`admission_campaigns`)**: Khởi tạo 13 đợt tuyển sinh năm 2026:
  - 5 đợt Tuyển sinh Trung cấp: `TC-2026-D01` đến `TC-2026-D05`
  - 8 đợt Tuyển sinh Đào tạo ngắn hạn: `NH-2026-D01` đến `NH-2026-D08`
- Tất cả câu lệnh INSERT đều sử dụng `ON CONFLICT (code) DO UPDATE` để đảm bảo tính idempotent.

## 5. Danh mục Kiểm thử Tự động (Self-Test Suite)

Lệnh thực thi: `npm run self-test:v0.8-a1`

- **TEST 1: Schema & Table Structure Invariants**: Kiểm tra cấu trúc 3 bảng, khóa chính UUID `gen_random_uuid()`, các cột bắt buộc và kiểu dữ liệu.
- **TEST 2: Foreign Key & Relational Integrity**: Kiểm tra ràng buộc khóa ngoại `ON DELETE RESTRICT` từ programs và campaigns sang groups, kiểm tra các index khóa ngoại.
- **TEST 3: Data Constraints & Validation Rules**: Kiểm tra ràng buộc duy nhất (code, group+year+period), ràng buộc năm (2000-2100), số thứ tự đợt (> 0), ngày kết thúc >= ngày bắt đầu, enum trạng thái và trình độ đào tạo.
- **TEST 4: Seed Data Verification & Fixtures**: Kiểm tra chính xác 2 nhóm `TRUNG_CAP` và `NGAN_HAN`, chính xác 13 campaigns năm 2026 (5 TC + 8 NH), tính duy nhất và tính idempotent.
- **TEST 5: Updated At Trigger & Timestamp Audit**: Kiểm tra trigger function và các trigger trước update cho cả 3 bảng.
- **TEST 6: Row Level Security (RLS) Policy Audit**: Kiểm tra RLS được bật trên cả 3 bảng, không có policy public/anon, kiểm tra phân quyền SELECT cho authenticated và quyền quản lý cho admin.
- **TEST 7: Idempotency, Safety & Zero Legacy Regression**: Kiểm tra tính an toàn của migration, không có lệnh phá hủy dữ liệu hay xóa bảng hiện hữu, đảm bảo không có UI/route/KPI nào bị ảnh hưởng.
