# v0.7-D1 Executive/BGH Dashboard Foundation

## Canonical Role
The canonical role for Executive/BGH is `executive`.

## Route
`/executive/dashboard`

## Route Access Rules
- Active Executive (`system_role === 'executive'`) can access it.
- Admin (`isAdmin === true`) can also access it (as per requirement to follow existing policy).
- Staff and Manager cannot access it.

## Read-Only Boundary
This dashboard is strictly read-only. API calls do not include any write actions.

## Components
- Reused: DateFilter, LoadingSkeleton (assumed from existing), ErrorBoundary (assumed).
- Created: `ExecutiveDashboardView`.

## Dashboard API
- Endpoint: `/api/dashboard/reporting` (via `dashboardApiClient.getStaffDashboard`).

## State Isolation
- State is isolated by `activeTab` and authenticated session. Switching tabs or logging out clears cached dashboard state.
