# v0.7-C6.2 – Missing Daily Report Reminder Backend & Idempotency

## Overview
v0.7-C6.2 introduces a secure, authorized backend endpoint for sending missing daily report reminders with server-side missing-report recheck and durable idempotency.

## Endpoint Route
- `POST /api/dashboard/team-monitoring/missing-report-reminder`
- `POST /api/manager/missing-report-reminder` (alias for compatibility)

## Request Contract
```json
{
  "employee_id": "...",
  "date_from": "YYYY-MM-DD",
  "date_to": "YYYY-MM-DD",
  "idempotency_key": "..."
}
```

## Core Behavior & Guarantees
1. **Authentication & Authorization**: Requires active Manager, Admin, or Executive role. Staff and viewer roles are forbidden (403).
2. **Scope Enforcement**: Server resolves manager unit scope and verifies target employee belongs to an authorized unit.
3. **Server-Side Missing Recheck**: Recalculates missing daily reports at send time. If no days are missing, returns `no_longer_missing`.
4. **Notification Service**: Reuses existing `manager_reminder` notification type and `notifications` table. Appears in Staff Notification Bell.
5. **Durable Idempotency**: Prevents duplicate notification creation on network retries or concurrent requests using `idempotency_key` stored in notification metadata (`action_url`). Returns `idempotent_replay: true` on replay.
6. **Write Boundary**: Restricted strictly to creating one notification record. No database migrations, no schema changes, no RLS updates, no UI additions, no bulk actions.
