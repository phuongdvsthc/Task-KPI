# v0.7-C1 – Manager Dashboard Foundation

## Overview
v0.7-C1 establishes the frontend foundation for the Manager Dashboard ("Tổng quan đơn vị"), providing role-protected access, date filtering, lifecycle data loading, loading/empty/error states, and reserved semantic sections for future manager modules (C2–C7) while keeping the Staff Dashboard and reporting services fully operational.

## Route & Access Control
- **Route / Tab ID**: `manager-dashboard` (`#/manager-dashboard`)
- **Access Rule**: Restricted to authenticated, active Manager, Executive, and Admin users. Staff users are strictly blocked and presented with an access-restricted notice.
- **Backend Scope**: Reuses the authenticated `/api/dashboard/reporting` endpoint. The backend reporting scope service resolves manager unit scope automatically without client-side privilege escalation or identity spoofing.

## Components Created & Reused
- **Created**: `src/components/dashboard/ManagerDashboardView.tsx`
- **Reused**: Shared Dashboard API client (`dashboardApiClient`), date filtering utilities, and UI layout primitives from AppLayout and Sidebar.

## Reserved Semantic Sections (C1 Placeholders)
1. Tổng quan công việc
2. Báo cáo hằng ngày
3. Chỉ số công việc
4. KPI đơn vị
5. Nhân viên cần theo dõi
6. Nội dung cần chú ý

## UI States & Safety
- **Loading**: Clean skeleton / loader state.
- **Empty**: Neutral message when no data is returned for permitted scope.
- **Error**: Safe Vietnamese error message with retry mechanism.
- **Stale Request Protection**: Request ID tracking ensures out-of-order responses never overwrite newer filter queries.
- **Read-Only**: Zero database write operations or side effects.
