# v0.7-C6.3 – Missing Report Reminder UI & Delivery Feedback

## Overview
v0.7-C6.3 introduces the user interface, confirmation dialog, idempotent action lifecycle, and delivery feedback for sending missing Daily Report reminders to authorized employees.

## UI Components Reused & Created
- **`MissingReportReminderModal`**: Dedicated accessible confirmation and feedback dialog for sending reminders.
- **`MissingReportsModal`**: Extended with a direct "Gửi nhắc" action button in the footer when missing days > 0.
- **`ManagerDashboardView`**: Extended with "Gửi nhắc" action buttons next to positive missing report counts in the team monitoring table.

## Action Location & Eligibility
- **Location**: Next to the positive missing report count in the employee monitoring table and inside the missing report detail modal.
- **Eligibility**:
  - Shown only for authorized employee rows.
  - Shown only when `missing_employee_days > 0`.
  - Zero or unavailable missing counts have no action.
  - Concise label: `"Gửi nhắc"`. After confirmed success, explicit action allows `"Gửi lại nhắc"`.

## Confirmation Dialog & Wording
- **Title**: `Xác nhận gửi nhắc báo cáo`
- **Content**: `Bạn sắp gửi thông báo nhắc {employeeName} kiểm tra và bổ sung {missingCount} lượt ngày chưa có báo cáo trong khoảng {dateFrom} đến {dateTo}.`
- **Behavior**: Opening the dialog sends no request. Canceling sends no request. Confirming sends exactly one request after backend verification.

## Idempotency-Key Lifecycle
- **New Explicit Action**: Generates a new `idempotency_key` (UUID) upon Manager confirmation.
- **In Flight**: Double-click or repeated clicks reuse the same key or are blocked by the `submitting` state.
- **Retryable Failure**: Network/uncertainty retries reuse the exact same `idempotency_key`.
- **Success / Replay**: `sent` and idempotent replays are treated as success.
- **New Resend**: Explicit "Gửi lại nhắc" requires confirmation and generates a new idempotency key.
- **Isolation**: Keys are never shared between employees and clear on logout or scope change.

## Feedback & Domain Results
- **Success (`status=sent`)**: Displays `Đã gửi nhắc báo cáo đến {employeeName}.`
- **No-Longer-Missing (`status=no_longer_missing`)**: Displays `Nhân viên không còn ngày thiếu báo cáo trong khoảng thời gian này.` and refreshes affected team data.
- **Error & Retry**: Network uncertainty shows `Chưa xác định được kết quả gửi. Bạn có thể thử lại.` with retry capability reusing the same key.

## Staff Bell & Write Boundary
- Creates the existing `manager_reminder` notification type.
- Respects the strict write boundary: no database schema changes, no migrations, no RLS changes, no modifications to Daily Reports, tasks, metrics, or KPIs.
