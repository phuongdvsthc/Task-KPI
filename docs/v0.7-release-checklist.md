# Phiên bản v0.7 Release Checklist – Dashboard & Reporting Experience

Tài liệu checklist bàn giao và các bước nghiệm thu kỹ thuật theo 4 giai đoạn chuẩn hóa.

---

## A. Checklist Trước Khi Commit (Pre-Commit Checklist)
- [x] **1. Kiểm tra Git Status / Diff:**
  - Không commit các file tạm thời, file build thừa ngoài `dist/`.
  - Đảm bảo các file `.env` chứa bí mật thật không bị đưa vào version control.
- [x] **2. Quét Bí mật (Secret Scan):**
  - Chạy quét toàn bộ mã nguồn và thư mục `dist/assets/*.js`.
  - Xác nhận không có `SUPABASE_SERVICE_ROLE_KEY` hoặc `GEMINI_API_KEY` trong client assets.
- [x] **3. Kiểm tra Cơ sở Dữ liệu & RLS (Database & RLS Audit):**
  - Xác nhận không tạo migration file mới ngoài ý muốn trong `supabase/migrations/`.
  - Xác nhận không nới lỏng hoặc thay đổi các chính sách RLS hiện hành.
- [x] **4. Kiểm tra TypeScript & Linter:**
  - Chạy `npm run lint` (`tsc --noEmit`) đạt kết quả 0 lỗi (Exit Code 0).
- [x] **5. Kiểm tra Build Production:**
  - Chạy `npm run build` tạo thành công `dist/index.html` và `dist/server.cjs`.
- [x] **6. Chạy Toàn Bộ Test Regression:**
  - Chạy `npm run self-test:v0.7` xác nhận 100% test suites từ A1 đến E5.4 đều đạt **PASS**.

---

## B. Checklist Trước Khi Triển khai (Pre-Deployment Checklist - Render / Cloud Run)
- [ ] **1. Thiết lập Biến Môi trường:**
  - Cấu hình đầy đủ các biến: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `GEMINI_API_KEY`, `APP_URL`.
  - Xác thực giá trị biến không chứa ký tự xuống dòng hoặc khoảng trắng thừa.
- [ ] **2. Kiểm tra Cấu hình Lệnh Build & Start:**
  - Build Command: `npm run build`
  - Start Command: `npm run start` (hoặc `node dist/server.cjs`)
- [ ] **3. Kiểm tra Health Check Endpoint:**
  - Xác nhận endpoint `/api/health` trả về `{ "status": "ok" }` với HTTP 200.
- [ ] **4. Xác nhận Yêu cầu Migration:**
  - Xác nhận v0.7 không yêu cầu chạy migration database mới trên production.

---

## C. Checklist Sau Khi Triển khai (Post-Deployment Verification)
- [ ] **1. Smoke Test Đọc Dữ liệu (Read-Only Smoke Test):**
  - Tải trang chủ `/` và kiểm tra phản hồi của shell giao diện.
  - Tải static assets (`index-*.css`, `index-*.js`) với HTTP 200.
- [ ] **2. Đăng nhập & Kiểm tra Phân quyền Từng Vai trò:**
  - Đăng nhập tài khoản **Staff**: Kiểm tra xem đúng bảng báo cáo cá nhân tại `/staff-dashboard`, không truy cập được `/manager-dashboard`.
  - Đăng nhập tài khoản **Manager**: Kiểm tra bảng giám sát nhóm và lọc đơn vị tại `/manager-dashboard`.
  - Đăng nhập tài khoản **Executive**: Kiểm tra trang tổng quan và so sánh đơn vị toàn trường tại `/executive-dashboard`.
  - Đăng nhập tài khoản **Admin**: Kiểm tra trang quản trị tại `/admin`.
- [ ] **3. Kiểm tra An toàn Thao tác Ghi:**
  - Không thực hiện các hành động write test với dữ liệu production.
  - Xác nhận việc tải và chuyển đổi bộ lọc Dashboard không sinh ra bất kỳ request ghi nào.
- [ ] **4. Kiểm tra Production Logs:**
  - Kiểm tra log máy chủ không in access token, mật khẩu hoặc khóa API bí mật.
  - Đảm bảo không có lỗi 500 hoặc ngoại lệ không bắt được.
- [ ] **5. Kiểm tra Giao diện Đa thiết bị (Mobile & A11y QA):**
  - Kiểm tra hiển thị responsive trên màn hình điện thoại (<= 640px) và máy tính bảng.
  - Kiểm tra độ tương phản màu sắc và khả năng thu phóng văn bản 200% trên trình duyệt thực tế.
