# v0.7-C5.1 – Manager Operational Charts

## Overview
v0.7-C5.1 implements Manager Operational Charts:
1. **Task-Status Comparison (Bar Chart)**: Visualizes mutually exclusive task status categories (`Đã hoàn thành`, `Đang thực hiện`, `Chưa bắt đầu`), with auxiliary indicators for `Quá hạn` and `Chưa có hạn hoàn thành`.
2. **Daily-Report Trend Over Time (Line Chart)**: Visualizes chronological reporting progression (`Lượt ngày đã báo cáo` in employee-days) using backend aggregate series data.

## Key Design Principles & Architecture
- **Single Source of Truth**: Powered directly by the unified Dashboard aggregate response (`UnifiedDashboardResponse`). No paginated C4 table rows or organization-wide frontend calculations are used.
- **Mutually Exclusive Task Categories**: Prevents overlapping categories in pie/donut compositions by using a clear categorical bar chart. Overdue and without-due-date categories are displayed as factual secondary information.
- **Employee-Day Terminology**: Consistently references reporting volume in employee-days (`Lượt ngày báo cáo`).
- **Filter Integration**: Fully respects current date range, unit selection, and employee filters.
- **Accessibility & Responsive Design**: Semantic headings, accessible descriptions, responsive Recharts containers, and neutral empty states when data is absent.

## Deferred Scope
- Metric charts and KPI charts are strictly deferred and not included.
- Employee ranking and comparison charts are omitted.
- Drill-down navigation, reminders, and write operations are excluded.
