# v0.9-D2 Rollback Runbook

## Tiêu chí Rollback
Rollback ngay nếu:
- Health check thất bại.
- Lỗi API 5xx tăng.
- User không đăng nhập được.
- `/api/access/me` thất bại.
- Admin mất quyền Access Control.
- Dữ liệu sai scope, Executive mutation, Admin bypass.
- Lộ secret.

## Kế hoạch Rollback
1. Dừng rollout.
2. Ghi thời điểm và lỗi.
3. Rollback Render về deployment/commit ổn định trước v0.9.
4. **KHÔNG** drop 6 bảng RBAC.
5. **KHÔNG** xóa access audit logs.
6. Xác nhận code cũ dùng `profiles.system_role`.
7. Chạy health check sau rollback.
8. Kiểm tra module chính: Login, Task, KPI, Report, Admissions.
9. Xác nhận không mất dữ liệu.

## Checklist sau Rollback
- [ ] Health PASS.
- [ ] Login PASS.
- [ ] Module chính (Task, KPI, v.v.) PASS.
- [ ] Không lỗi 5xx.
- [ ] Incident note đã được ghi.
