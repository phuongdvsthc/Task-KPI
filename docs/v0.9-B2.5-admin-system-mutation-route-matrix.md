## Security Guarantees
1. **No System Role Reliance**: B1 capability checks (`users.manage`, `units.manage`, `system.manage`) supersede all legacy `profiles.system_role` and `authenticateAdmin` checks.
2. **Executive Restriction**: Executives possess `all` view scope but lack mutation capabilities, resulting in immediate 403 on all admin mutation routes.
3. **Secret Masking & Protection**: API keys and secrets in settings or AI config are masked in responses and never logged or exposed.
