# v0.7-C4.2 – Manager Employee Monitoring Table

## Overview
The Manager Employee Monitoring Table component renders a responsive, tabular view of work, reporting, and KPI metrics for employees within the authorized reporting scope, powered by the C4.1 Team Monitoring API (`GET /api/dashboard/team-monitoring`).

## Specification & Architecture

### 1. API Client & Endpoint
- Endpoint: `GET /api/dashboard/team-monitoring`
- Client Method: `dashboardApiClient.getTeamMonitoring(filters)`
- Supported Parameters: `date_from`, `date_to`, `organization_unit_id`, `employee_id`, `page`, `page_size`, `sort_by`, `sort_order`.
- Authentication: Bearer token included via existing authenticated request helper.

### 2. Table Location & Title
- Section Title: **Theo dõi nhân viên**
- Description: **Tổng hợp công việc, báo cáo và KPI của nhân viên trong phạm vi đang chọn.**
- Position: Placed after the Manager Summary Cards section in the Manager Dashboard (`ManagerDashboardView.tsx`).

### 3. Table Columns & Mapping
1. **Nhân viên**: `employee.display_name` + employee code / job title. (Email/phone absent; ID used as internal key).
2. **Đơn vị**: `employee.organization_unit_name`.
3. **Công việc**: `tasks.completed / tasks.total` (with active tasks count).
4. **Quá hạn**: `tasks.overdue` (highlighted if > 0).
5. **Báo cáo còn thiếu**: `daily_reports.missing_employee_days` (employee-days).
6. **HT báo cáo**: `daily_reports.completion_rate` formatted as percentage.
7. **KPI giao**: `kpis.assigned`.
8. **Kết quả KPI**: `kpis.achievement_rate` or `weighted_score` appropriately labeled.
9. **Trạng thái dữ liệu**: Factual attention status badges mapped from attention codes.

### 4. Status Label Mapping
- `overdue_tasks` -> "Có công việc quá hạn"
- `missing_daily_reports` -> "Thiếu báo cáo"
- `kpi_pending_review` -> "KPI chờ đánh giá"
- `kpi_missing_actual_value` -> "KPI chưa có số liệu"
- `metric_data_unavailable` -> "Chưa có dữ liệu chỉ số"

### 5. Filter Integration
- Reacts to active Manager filters (`date_from`, `date_to`, `organization_unit_id`, `employee_id`).
- Changing filters resets pagination to page 1.
- Refresh reloads summary cards and table using identical filter scope.

### 6. Pagination & Sorting
- Server-side pagination via C4.1 metadata (`page`, `page_size`, `total_pages`, `total_items`).
- Server-side sorting on allowed sort fields (`organization_unit_name`, `display_name`, `task_completion_rate`, `kpi_achievement_rate`, `total_tasks`), defaulting to non-ranking order.

### 7. States
- **Loading**: Table-level loading spinner, summary cards remain visible, no fake rows.
- **Empty**: "Không có nhân viên hoặc dữ liệu phù hợp với bộ lọc hiện tại."
- **Error**: Table-level error alert with retry button, preserving other dashboard sections.
- **Partial**: Null values displayed neutrally as "Chưa có dữ liệu".

### 8. Read-Only Guarantee
- Zero state mutations, zero database writes, zero reminders, zero task updates.
