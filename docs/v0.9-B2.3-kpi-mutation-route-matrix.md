## Security Guarantees
1. **No System Role Reliance**: B1 capability checks and data scope resolution supersede all legacy `profiles.system_role` checks.
2. **Executive Restriction**: Executives possess `all` view scope but lack mutation capabilities (`kpi.assign`, `kpi.update`, `kpi.delete`, `kpi.lock`, `kpi.review`, `kpi.update_actual`), resulting in immediate 403 on all mutation routes.
3. **Data Scope Enforcement**: Staff and Managers are strictly restricted to their assigned data scope (`own`, `unit`, `unit_tree`); attempts to process KPI outside scope or spoof unit/user IDs return 403.
4. **IDOR & Spoofing Prevention**: Session tokens dictate actor identity (`entered_by`, `reviewer_id`, `assigned_by` validation against scope); client payloads attempting actor/reviewer/unit spoofing are rejected.
5. **Revocation Resilience**: Revoking a role or permission immediately blocks subsequent requests with 403.
